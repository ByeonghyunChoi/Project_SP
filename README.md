# Chronoclasm (크로노클라즘)

**Unreal Engine 5.5 · C++ / Blueprint / GAS · 3D 턴제 로그라이트 RPG**

시간의 신이 인간으로 추방된 뒤, 시간을 조작하며 다시 신의 자리를 되찾아가는 다크 판타지 게임입니다.  
무기 선택과 패링, 유물·오파츠의 효과를 활용해 전투를 진행합니다.

## 구현 및 문제 해결

### 01. 유물·오파츠 — 전투 코드와 이벤트로 연결

**왜 나눴나**

처음부터 모든 유물 기능을 전투 코드에 직접 추가하면, 유물이 늘어날 때마다 다른 프로그래머가 담당한 영역을 함께 수정해야 했습니다. 실제 팀 작업에서는 Git 병합과 수정 범위가 겹치는 부분도 고려해야 했습니다.

**어떻게 구현했나**

전투 쪽에서는 행동이 발생했다는 **Gameplay Tag 이벤트**를 전달하고, 유물·오파츠 어빌리티에서는 `AbilityTask_WaitGameplayEvent`로 필요한 이벤트를 기다리도록 구성했습니다.

### 02. 보상 UI — 데이터와 팝업의 호출 순서 맞추기

**발생한 문제**

상자를 열었을 때 재화는 정상적으로 들어오는데 **획득 팝업이 비거나 이전 데이터가 표시**되는 문제가 있었습니다.

기존에는 인벤토리 변경 알림에 따라 UI가 데이터를 확인했습니다. 그런데 보상 큐가 갱신되기 전에 UI가 먼저 읽는 경우가 있었습니다.

**수정한 방식**

보상 큐를 초기화하고 최신 데이터를 설정한 **다음**, 보상 UI 전용 델리게이트를 `Broadcast`하도록 호출 순서를 수정했습니다.

### 03. 대화 시스템 — 누락 데이터와 반복 입력 처리

대화 데이터 테이블에서 내용을 읽어오고, 화자 이미지와 대사 내용을 UI에 표시하는 기능을 구현했습니다. 개발 중에는 다음 문제들을 확인했습니다.

| 문제 | 수정한 부분 |
| :--- | :--- |
| NPC 일러스트가 없는 대화에서 `nullptr` 크래시 발생 | 이미지 유효성을 검사하고, 누락 시 빈 이미지로 처리 |
| 첫 화자 이미지가 늦게 표시됨 | 대화 시작 전에 사용할 이미지 에셋을 먼저 찾도록 수정 |
| 스킵 버튼을 연속 입력할 때 타이머·사운드 중복 | `Timer Handle`을 이용해 중복 실행을 제어 |

### 04. 플레이어 스탯 — 공동 세이브 시스템과 연동

**공동 작업과 내 담당 부분을 구분했습니다.**

세이브 시스템은 다른 프로그래머와 함께 작업했습니다. 게임에서 **사망하면 지워야 할 진행 데이터**와 **사망 후에도 유지할 영구 강화 데이터**를 구분해야 했습니다.

저는 이 과정에서 **플레이어 스탯 저장·복원에 관련된 부분**을 맡아, 영구 강화 데이터를 캐릭터 재생성 후 GAS `AttributeSet`에 반영하도록 연결했습니다.

![세이브 슬롯 구분 및 플레이어 스탯 복원 흐름](docs/images/save-player-stats-flow.png)

| 구분 | 역할 |
| :--- | :--- |
| **`Slot_Run`** | 현재 진행 중인 플레이 데이터. 사망 시 초기화 |
| **`Slot_Perm`** | 영구 강화 등 사망 이후에도 유지할 데이터 |
| **플레이어 스탯 연동 (내 담당)** | 영구 데이터 저장·로드 및 캐릭터 재생성 후 기본 스탯 적용 |

**바뀐 점**  
진행 데이터의 초기화와 영구 강화 스탯의 복원을 구분해, 맵 이동이나 캐릭터 재생성 이후에도 필요한 성장 데이터를 다시 적용하도록 했습니다.
